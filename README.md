# Company-Specific Password Manager Prototype

## Run

```bash
npm install
npm run dev
```

Use a current supported Node.js version.

## Trial access details

- Administrator: `admin` / `Admin123!`
- Employee: `anegoie` / `Welcome123!`

## Included

- Administrator and employee roles
- Create, deactivate, reactivate and delete employee accounts
- Delete employee password records when an employee is deleted
- Add, edit, delete, search, reveal and copy password records
- 80-day warning and 90-day overdue reminder
- More-than-six-consecutive-character similarity check
- Browser local storage for demonstration data

## Important limitation

This is a BSU VAULT frontend prototype created for the BSU project. Login details and stored passwords are kept in browser local storage and are not secure. Use fictional information only. A real company application needs a backend, encrypted records, hashed login passwords, secure sessions, audit logs and server-side access control.
